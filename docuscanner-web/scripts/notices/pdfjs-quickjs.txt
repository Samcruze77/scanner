Notices for the QuickJS engine served as /pdfjs/wasm/quickjs-eval.wasm and quickjs-eval.js
===========================================================================

These two files are byte-identical (SHA-256 compared 2026-10-26) to external/quickjs/quickjs-eval.wasm and quickjs-eval.js in https://github.com/mozilla/pdf.js,
whose README says: "Quickjs and pdf.js.quickjs are released under MIT license so quickjs-eval.js is released under MIT license too." The two licence files that
folder carries (LICENSE_QUICKJS and LICENSE_PDFJS_QUICKJS) are copied below; the pdfjs-dist 6.3.289 npm package omits them. PDF.js only runs this engine for PDF form
scripting (the enableScripting option), which this website does not enable.
